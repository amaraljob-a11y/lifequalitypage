# Life Quality Med — GitHub Pages

Publique todos os arquivos desta pasta no repositório do GitHub. O arquivo de entrada é `index.html`.

- `index.html`: página principal
- `styles.css`: estilos responsivos
- `script.js`: menu, animações e formulário para WhatsApp
- `assets/`: logotipo e imagens locais

No GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
